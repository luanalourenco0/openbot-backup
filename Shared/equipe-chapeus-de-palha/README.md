# Equipe Chapéus de Palha (OpenBot)

Equipe de agentes de IA do Luan, tema One Piece, feita para o OpenBot. Rascunho v2, 2026-10-31.

## Arquivos

- `GUIA-OPENBOT.md`: passo a passo para montar a equipe no app.
- `AGENTS.md`: contexto comum, lido por todo agente. Tem a tabela de quem é quem, provedor e modelo.
- `agentes\`: instruções prontas de cada agente (Luffy, Nami, Franky, Chopper, Zoro, Usopp, Sanji, Robin e Jinbe, o do Gemini), para colar no app.
- `contexto\`: estado do projeto, decisões e plano de integração de memória.
- `registro-aprovacoes.md`: o que foi pedido, aprovado e feito. Só o Luffy e o Luan editam.
- `exportacao\briefing-chatgpt-codex.md`: resumo curto e datado para colar no ChatGPT, que não lê arquivos locais.
- `privado\`: dados pessoais (currículo, perfil). Fora de sincronização e de git. Ainda não criada.
